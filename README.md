# Quartz Breakout (DAQ-16-BNC-2U Version)

Made in KiCad 9.0.7

- 2 PCBs side by side mounted behind a 2U panel 
- Remote (originally meant for long multiconductor cable but could be used differently)
- Stuffing options to connect the D shell and 5 ground pins to the panel 
- 3.4 mm mounting holes to fit M3 screws, or standoffs that would need to be 0.54 in/13.72 mm (mechanically optional as BNCs have their own mounting, but also provides ground)
